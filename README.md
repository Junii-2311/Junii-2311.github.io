# Junaid Zaheer — portfolio

Personal site: **https://junii-2311.github.io**

Plain HTML, CSS and JS, no build step. The page assembles itself on load: a crew of
named agent cursors frames, types and colours each section as it scrolls into view
(skippable, and switched off for visitors who prefer reduced motion). The four system
demos are simulations with sample data.

- `index.html`, `styles.css`, `script.js` — the site
- `assets/Junaid-Zaheer-Resume.pdf` — résumé, printed from `resume/resume.html` with headless Chrome
- `assets/portrait.webp` — hero photo

Preview locally: `python -m http.server 8765`, then open http://127.0.0.1:8765
